Light mode – Forgot PIN recovery

Phone (390×844)
Set new PIN
Enter the code from your sticker to set a new one.
Where to find it: Check the sticker on the back of your t@sk4ce box.
After reset: All parents get alerted, all sessions sign out, and the sticker code locks until re-armed in Settings.
Can't reach the sticker?
sudo tskfrce-reset --pin
