# Feature guides

One page for each t@sk4ce feature, with the steps in more detail than the [everyday use](../04-everyday-use.md) chapter.

- [Homework mode](homework.md): open only the school sites for a set time.
- [Time banking](time-banking.md): let kids save unused screen time.
- [Prices per device group](group-pricing.md): charge more points for some devices.
- [Less parent work](less-parent-work.md): trust mode, bedtime auto-approve and the weekly recap.
- [Calm screens](calm-screens.md): why the parent screens show less, and where things moved.
- [Rewards and celebrations](rewards-celebrations.md): celebrations and Happy Hour.
- [Minigames](minigames.md): quick games kids earn by doing chores.
- [Goals](goals.md): kids save points toward something bigger.
- [Small devices and Postgres](small-devices.md): run on a Raspberry Pi, and optionally move to Postgres.
- [Networks and Wi-Fi](networks-and-wifi.md): block devices on every network, and change the box's Wi-Fi.

More pages are added here as they are written.
