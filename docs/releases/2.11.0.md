# 2.11.0: Setup presets

## New

- **How strict should it be?** is a new setup step after Kids. Pick **Relaxed**, **Balanced** or **Strict**. Balanced is the default.
- **Your plan** shows what your pick sets for each kid. Looks good finishes. **Tweak** opens Chores, Hours and Optional extras, filled in from the plan.
- **Each kid's age shifts the plan.** Little kids get fewer chores, less screen time and an earlier bedtime. Teens get more time and later hours.
- **Different for each kid.** With 2 or more kids, switch it on to pick a style for each one.
- **See what this sets.** A collapsed table shows the limits, one column per kid. Goals and banked time follow the family pick.
- **Switch style later.** Settings → Family → **Style** changes the family. Each kid page has its own style switch.
- **The switch shows what changes first.** It keeps any setting you already edited.
- **Internet locks until chores are done.** Each kid page has its own switch for this.

## Changed

- **Setup has 7 steps now.** They are You, Family, Kids, How strict, Your plan, Kids' phones (optional) and Devices.
- **Families part way through setup resume at How strict.**
