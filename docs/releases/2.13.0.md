# 2.13.0: Runs on smaller boxes

## Changed for every family

- **Lighter and quicker on small boxes.** On a Raspberry Pi 4 class box, the whole app now idles at about 230MB (was 260MB).
- **Device blocking is checked faster.** The check the home box runs constantly is 2-7x faster, and it no longer slows down as you add devices.
- **Gentler on SD cards.** The database writes to the card less often. A power cut can at most lose the very last change; the database itself stays intact.
- **Backups before upgrades are complete.** The automatic backup taken before an upgrade now includes changes that had not been written into the main database file yet.

Nothing to do: existing boxes keep their data and upgrade as usual.

## New and optional

- **Use your own Postgres server.** Families with a database server, or who want to take load off a small box, can point t@sk4ce at Postgres.
- **Move an existing box to Postgres** with one command, run from the install folder: `bash scripts/db-migrate.sh postgres://user:pass@host/db`.
  - It backs up first and checks every table's row count before switching.
  - If anything fails, the box keeps running on its untouched SQLite database.

## For builders

- `scripts/tier.sh <tier> gate` runs the full stack capped like a Pi 4 2GB, old laptop, Pi 3 1GB or Pi Zero 2 W (`--arm64` for real arm64 images under QEMU).
- CI runs the tests on SQLite and Postgres, runs the blocker unit tests, and gates the Pi 4 tier plus a 10-minute memory soak.
- Findings: `docs/perf/2026-11-profile.md`.
