# 2.13.0: Less work for parents

2.7.0 to 2.12.0 were branch versions and were never released. 2.13.0 is the first release since 2.6.0, so it includes all of them.

## New for every family

- **Less parent work.** Trust mode, bedtime auto-approve and a weekly recap. See [Less tapping](../guide/04-everyday-use.md#less-tapping).
- **Calmer parent screens** with shared widgets.
- **Goals.** Kids save toward parent-priced goals, with a mascot party when one is fulfilled. See [2.10.0](2.10.0.md).
- **Goals can grant screen time** (the extra-screen-time goal) or cancel a penalty (a **Get out of jail free** card).
- **Penalties with earn-back.** Small, Medium, Big or Custom. Kids do make-up chores to shrink a penalty. A penalty for everyone can take points from a family goal or raise its price.
- **Setup presets.** One "How strict?" choice sets chores, hours and extras by age. See [2.11.0](2.11.0.md).
- **Homework mode.** Study sites stay open while the internet is otherwise paused. See [2.9.0](2.9.0.md).
- **Minigames.** Chores earn quick games. See [2.12.0](2.12.0.md). The new look uses 3D art and "living sticker" mascots, loaded only when a game opens.
- **Runs on small devices.** The app starts lighter and does less work in the background, so a Raspberry Pi copes better.

## Opt-in

- **Penalties:** off until you turn them on in **Settings → Family → Penalties**. A penalty is always your tap.
- **Trust mode** (per kid) and **bedtime auto-approve:** off until you switch them on.
- **Postgres:** for larger setups. Set `DATABASE_URL`, or move an existing box with `bash scripts/db-migrate.sh <postgres url>`. It keeps your SQLite file as a backup. Most families don't need this.

## Fixes

- **Blocks apply right away.** The backend could not reach the blocker in the standard install, so blocks waited up to 30 seconds and **Test block** failed. The blocker now also listens on the Docker bridge gateway.
- **Updates keep your version.** The installer now remembers the image tag in `.env`, so a restart or reboot no longer falls back to `:latest`.
