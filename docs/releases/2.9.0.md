# 2.9.0: Homework mode

## New

- **Homework mode.** A paused device can open only school sites for a set time. Start it from a device or group's **…** menu (30 min, 1 hour, 90 min or 2 hours).
- **Kids can ask for homework time.** The request shows in **Needs you**. **Approve** gives 1 hour; the row's **…** has other lengths and **Decline**. After a no, the kid can ask again in 5 minutes.
- **Homework sites.** **Settings → Homework** has the family list and "Never during homework". Each kid page has a **Homework sites** row for that kid's extras.
- **Homework activity.** While homework mode is on, the device page shows what sites were used, so you can block or add them.

## Limits

Big school sites share servers with other sites. A determined kid can sometimes reach another site on the same servers. Check **Homework activity** for names you don't recognise.
